# Issue Tracker

Issues for this repository are tracked in Linear.

## Workspace

- Workspace: `memoji-inc`
- Team: `Memoji inc` (`MEM`)
- Project: `a11y-agent`

## Creating issues

Create new issues in the `Memoji inc` team and associate them with the `a11y-agent` project.

Use a concise, outcome-oriented title. The description should include:

- Context and motivation
- Acceptance criteria
- Relevant implementation constraints
- Links to related issues, pull requests, or domain documentation

## Recommended workflow

Use these statuses:

1. `Triage` — newly reported and awaiting evaluation
2. `Backlog` — accepted but not scheduled
3. `Todo` — ready and selected for implementation
4. `In Progress` — actively being implemented
5. `In Review` — awaiting review or verification
6. `Done` — completed and verified
7. `Canceled` — closed without implementation

If the Linear team uses different status names, map them by meaning rather than creating duplicates.

## Triage

Use the label mapping in `docs/agents/triage-labels.md`. Status represents delivery progress; labels represent triage disposition.

When the configured team or project cannot be found, stop and ask for the tracker configuration to be corrected rather than filing the issue in an unrelated location.
